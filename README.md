# 🚀 GroupSync — Enterprise Emergency Project Recovery Engine
*QUEST 02: Build The Alarm*

GroupSync is a high-performance, real-time project recovery and telemetry dashboard built for student and engineering teams to intercept communication gaps, track critical risks, and prevent deadline penalties.

---

## 🌟 Key Features

* **🚨 Emergency Countdown & Penalty Tracker:** Live real-time monitoring of grace periods and grade deduction penalty windows.
* **📊 AI Root Cause Diagnostics:** Live interactive telemetry gauges tracking **Failure Risk**, **Git Commit Velocity**, and **Team Sync Health**.
* **📋 Dynamic Kanban Milestone Board:** Interactive task management with structured states (*Critical Blockers*, *Delayed / In Progress*, *Done / Verified*) and real-time status toggles.
* **🤖 Professor Roast Simulator Mode:** An advanced AI-simulated evaluator critique mode that breaks down where judges or professors would look for flaws (e.g., SQL normalization issues, missing ER diagrams).
* **⚡ Autonomous Panic Interceptor:** Proactive alerts targeting communication drop-offs and suggesting instant team rescue actions.

---

## 🛠️ Tech Stack & Architecture

* **Frontend:** HTML5, CSS3, Vanilla JavaScript, Alpine.js
* **Styling & Aesthetics:** Tailwind CSS (via CDN), Cyber-Dark mode with frosted glassmorphism (`backdrop-filter: blur`), custom cubic-bezier spring physics, and neon gradients.
* **Icons:** Lucide Icons

---

## ▶️ How to Run Locally

Because GroupSync is built as a lightweight, optimized Single-Page Application (SPA), it requires no complex backend dependencies or package installations.

1. Clone or download this repository.
2. Open the project folder.
3. Double-click on **`index.html`** (or open it via Live Server in VS Code) to launch it instantly in any modern web browser.
